## 今日决策记录
- **决策**：暂停 035 paid matrix，先做 cross-domain prompt 资格验证（Proposal 002 + 三票）
  - 原因：high/max 两臂共享同一 ML 偏置 prompt，比较的是偏离任务目标的生成行为；cross-domain-v1 未通过则 paid reasoning-effort 与 Scale Gate 继续 fail-closed 暂停
  - 替代：8 套 cluster-specific prompt——否决（向模型暴露私有 cluster 元数据、引入分类分支与错误路由）
- **决策**：跨会话边界收紧为 zero-provider-call 而不只是"零费用"
  - 原因：authenticated 探测也会意外形成未纳入 24-run 矩阵的模型证据
- **决策**：5.00 CNY 升格为 observed-spend 重审批阈值，30.00 为唯一 Canary 硬上限，每 slot request 前按 `current actual + 7.08 ≤ 30.00` reservation
  - 原因：post-hoc ingest 只能拒绝记录、不能撤销已发生费用；硬保证必须发生在不可逆 provider request 之前
  - 替代：压低 max_tokens / 依赖低谷价 / 用 smoke 均值——分别改变实验变量、依赖时段边界、把期望值冒充最坏界，全拒
- **决策**：执行模式选 A（串行 + 周末低谷 + 盲审/provider 等待流水线化），不选 B（pair 内并行 k=2）
  - 原因：周末低谷直接减半实际成本；并行仅省 12-40 分钟，不值合同修订 + 命令重冻结 + 双进程交互批准竞态的风险
- **决策**：execution-code pin 用私有 package 内 write-once 文件，不塞进 frozen matrix
  - 原因：避免 tracked Proposal hash 与自身 commit 循环引用；pin 创建先于 reservation，崩溃后同 commit 重试幂等
- **决策**：生产 transport 选 exact-pinned `httpx==0.28.1` direct HTTP，不用 OpenAI SDK / curl / 临时 injector
  - 原因：exact request/raw response 边界、显式零重试、可审计的唯一 CLI 路径；trust root 必须来自命令中预先登记的 file hash（外部 pin），不能只信同一文件内的 self-pin
