## 今日决策记录

- **决策**：新 ideation runtime 使用 Python 3.13 reference minor，并永久保留 portable CPU FP32 reference path。**原因**：兼顾 Windows/macOS 当前 wheel、维护周期与可移植性。**替代方案**：Python 3.11 降为历史 compatibility evidence；accelerator 只有在 CPU 未通过 latency gate 且证明至少 2 倍净收益时才作为可选 backend。
- **决策**：Workshop、corpus、retriever 和 run evidence 分别使用严格 model-visible/private boundary。**原因**：从结构上阻止 Target answer leakage、跨 case 检索、动态 metadata 污染和不可审计结果释放。**替代方案**：拒绝 raw Target 内容直送模型、global runtime catalog join、remote/global retrieval fallback 和事后补日志。
- **决策**：DeepSeek adapter v1 只实现 non-streaming Chat Completions。**原因**：当前文本 protocol 下更小、更透明，并保留完整 usage/cache/finish diagnostics。**替代方案**：Responses API 等 schema-driven protocol 与 paired canary 证明净收益后再版本化迁移，不做运行时双 endpoint fallback。
- **决策**：Local ranking 先做 exhaustive score-all comparative prototype，不从文献或直觉直接选 BM25、dense 或 hybrid。**原因**：每 case 仅 3–36 篇 references，ANN 无必要且可能破坏完整候选边界；最终选择必须基于 blind holdout、determinism 和 resource gates。**替代方案**：SPLADE、ColBERT、cross-encoder、LTR、citation graph 等重方案仅在第一轮 failure evidence 对应其机制优势时再进入新 protocol。
