- 响应 Robert「从第一性原理出发做一轮全面的对抗性审查」指令，对 DeepSeek Adapter 与 Model Round 执行链路开展对抗性压力分析，深挖 7 处边界弱点并实施防御性加固：
  1. **强制 Audit Release Gate（Critical）**：在 `execute_round` 入口实施 fail-closed 强校验，若 `store` 或 `run_id` 缺失立即抛出 `AUDIT_RELEASE_GATE_FAILED`，杜绝未留痕模型结果放行；

  3. **兑现「失败 Attempt 也计费」契约（High）**：对 HTTP 200 但因 `truncated`（`length`）或 `resource_exhausted` 导致 round 失败的 attempt，解析其真实 usage 并计费，落盘至 `failure.json` 与 `provider_attempt.finished` 事件；
  4. **Wire Bytes 原生捕获（Ticket 023 契约闭环）（High）**：落盘 `response.json` 直接保存 `transport_resp.body` 原始字节切片，禁止再次 `canonical_json_bytes` 格式化；

  6. **System Message 严格排位唯一性（Medium）**：强制限制 `system` 角色消息仅能位于 `messages[0]` 且最多出现一次；
  7. **User ID 格式安全校验（Medium）**：强制 `^[A-Za-z0-9_\-\.]{1,128}$` 正则，杜绝控制字符与注入风险。
