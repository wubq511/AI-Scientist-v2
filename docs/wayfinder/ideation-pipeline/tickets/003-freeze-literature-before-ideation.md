## Question

May literature metadata be fetched while an Ideation Run is in progress?

## Resolution

No. A separate preprocessing phase may use public sources to enrich missing fields and must freeze provenance and hashes. During an Ideation Run, literature retrieval is local to the Target Reference Corpus and fails closed when that boundary cannot be proven.
