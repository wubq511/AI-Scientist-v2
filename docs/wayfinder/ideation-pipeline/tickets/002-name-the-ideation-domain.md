## Question

Which terms prevent ideation work from being confused with prohibited downstream experiments?

## Resolution

Use the canonical language in `CONTEXT.md`: Ideation Pipeline, Ideation Run, Target Reference Corpus, Scoped Literature Retriever, Evidence Chain, Evidence Feedback Loop, Run Isolation, and Downstream Experiment. Reserve “experiment” for the prohibited downstream phase.
